The roadmap lives in GitHub issues, so it's never out of date the way a page would be. Every planned feature is an open issue labelled [`roadmap`](https://github.com/CharanMN7/ig-comment-dm/issues?q=is%3Aissue+is%3Aopen+label%3Aroadmap).

## By area

| Area | What's in it |
|---|---|
| [Automation](https://github.com/CharanMN7/ig-comment-dm/issues?q=is%3Aissue+is%3Aopen+label%3A%22area%3A+automation%22) | Triggers, keywords, DM content and delivery: button templates, follow gates, `{username}` placeholders, negative keywords |
| [Matching](https://github.com/CharanMN7/ig-comment-dm/issues?q=is%3Aissue+is%3Aopen+label%3A%22area%3A+matching%22) | Keyword matching and text normalisation |
| [Analytics](https://github.com/CharanMN7/ig-comment-dm/issues?q=is%3Aissue+is%3Aopen+label%3A%22area%3A+analytics%22) | Totals, charts, per-rule performance, follower history |
| [Instagram API](https://github.com/CharanMN7/ig-comment-dm/issues?q=is%3Aissue+is%3Aopen+label%3A%22area%3A+instagram-api%22) | More of Meta's Graph API: the `messages` webhook, a DM inbox, typed Meta errors |
| [Operations](https://github.com/CharanMN7/ig-comment-dm/issues?q=is%3Aissue+is%3Aopen+label%3A%22area%3A+ops%22) | Migrations, health checks, exports, monitoring |
| [Admin panel](https://github.com/CharanMN7/ig-comment-dm/issues?q=is%3Aissue+is%3Aopen+label%3A%22area%3A+ux%22) | Onboarding and presentation: dark mode |

Each issue also carries an effort label: [`effort: small`](https://github.com/CharanMN7/ig-comment-dm/issues?q=is%3Aissue+is%3Aopen+label%3A%22effort%3A+small%22) is roughly an evening, `effort: medium` is a few sessions, and `effort: large` needs a design decision before anyone builds it.

## Picking one up

Start with [`good first issue`](https://github.com/CharanMN7/ig-comment-dm/labels/good%20first%20issue): those are self-contained and have the approach sketched out in the description. Comment to claim the issue and wait to be assigned before you start; [Contributing](/contributing#claim-an-issue-first) explains why.

## Suggesting something

[Open a feature request](https://github.com/CharanMN7/ig-comment-dm/issues/new/choose). Check the open issues first, and read [what belongs here](/contributing#deciding-what-belongs-here): this stays a tool you run yourself, so a hosted multi-tenant version or a paid tier won't make the list.

For ideas that aren't a feature yet, there's [Discussions](https://github.com/CharanMN7/ig-comment-dm/discussions).
